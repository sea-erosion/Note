# ✦ 小説執筆ツール

ブラウザで完結する、シングルHTMLファイルの小説執筆ツールです。  
インストール不要。`novel_tool.html` をダブルクリックして開くだけで使えます。

---

## 動作環境

| 項目 | 内容 |
|------|------|
| 形式 | シングルHTMLファイル（`novel_tool.html`） |
| 動作 | モダンブラウザ（Chrome / Edge 推奨） |
| インストール | 不要 |
| オフライン | 対応（AI支援・ZIP機能を除く） |
| データ保存 | ブラウザの localStorage に自動保存 |

---

## 機能一覧

### エディタ

- **横書き / 縦書き切替**（ROT ボタン）
- **フォントサイズ変更**（数値入力）
- **リアルタイム文字数カウント**（シーン単位）
- **UNDO / REDO**（最大80段階）
- **検索 / 次へ**（本文内をインクリメンタル検索）
- **全置換**（検索ワードを一括置換）
- **全文コピー**（全章・全話を結合してクリップボードへ）
- **X（旧Twitter）投稿**（本文冒頭100字をポスト）

### 章・話の管理（サイドバー）

- 章と話の **2階層構造**で管理
- **章名・話名のインライン編集**（✎ボタン または エディタ上部の入力欄）
- **章の追加・削除**
- **話の追加・削除**（章ごとに独立）
- 選択中の章・話がハイライト表示

### ファイル操作

| ボタン | 動作 |
|--------|------|
| LOAD | ローカルのテキストファイルを開く（UTF-8 / Shift-JIS 自動判別） |
| OVERWRITE | 開いたファイルに上書き保存 |
| NEW SAVE | 全章・全話を1つの `.txt` ファイルとして書き出し |
| COPY ALL | 全文をクリップボードにコピー |

### バックアップ（BACKUP ボタン）

- **手動バックアップ**：任意のタイミングで作成
- **自動バックアップ**：30分ごと、およびブラウザを閉じる直前に自動実行
- **履歴から復元**：最大20件保持（古いものから自動削除）
- **全件エクスポート**：バックアップ履歴ごと `.json` ファイルに書き出し
- **ファイルから復元**：エクスポートした `.json` を読み込んで復元

### ZIP出力 / ZIP読込

出力されるZIPの構造：

```
作品名_YYYYMMDD_HHMM.zip
├── index.json                 # 全体メタ（設定・登場人物・構成一覧）
├── ch01_第一章/
│   ├── chapter.json           # 章メタ（文字数など）
│   ├── ep01_第一話.txt        # 本文テキスト
│   ├── ep01_第一話.json       # 話メタ
│   ├── ep02_第二話.txt
│   └── ep02_第二話.json
└── ch02_第二章/
    └── ...
```

- **ZIP出力**：現在のデータを上記構造でzip化してダウンロード
- **ZIP読込**：ZIPを読み込み、章・話・本文・設定・登場人物を完全復元
- 外部エディタで `.txt` を編集したあとに再読込することも可能
- ※ ZIP機能はオンライン環境が必要（JSZipをCDNからロード）

### AI執筆支援（右パネル）

- **クイック指示**ボタン：続きを書く・改稿・心理描写・情景描写・会話改善・要約
- **カスタム指示**：自由入力でAIへ指示
- 本文の末尾300字を自動的にコンテキストとして送信
- 作品設定・登場人物の情報もAIへ反映
- 生成結果を「本文に追記」「置き換え」「コピー」で利用
- ※ オフライン時はボタンが無効化され、メッセージが表示されます

### 登場人物管理（右パネル）

- 名前・役割・年齢・外見・性格を登録
- 登録情報はAI支援のプロンプトに自動反映
- 追加・削除が自由

### 作品設定（右パネル）

- タイトル・ジャンル・舞台/世界観・あらすじ・自由メモを記録
- AI支援の品質向上に使われる

### 執筆目標・進捗（右パネル）

- **総文字数目標**：達成率をリングで表示
- **今日の目標**：日次文字数を設定
- **日次記録**：任意のタイミングで文字数を記録（最大30日分）
- サイドバーの進捗バーにも総合達成率を表示

## データの保存場所

| データ | 保存先 |
|--------|--------|
| 執筆データ（章・話・本文・設定） | `localStorage` (`novel_data`) |
| バックアップ履歴 | `localStorage` (`novel_backups`) |

> ブラウザのデータを削除するとすべて失われます。定期的にZIPまたはJSONでエクスポートしてください。
